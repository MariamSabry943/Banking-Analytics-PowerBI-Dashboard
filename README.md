# 🏛️ Banking Analytics Power BI Dashboard

An end-to-end business intelligence project designed to transform raw banking data into actionable executive insights. 

## 🚀 Project Overview
This project covers a complete data analysis lifecycle, from initial UI/UX wireframing in Figma to ETL processing, relational data modeling, and advanced DAX measure calculations in Power BI.

## 📊 Dashboard Pages & Features
- **Executive Overview:** High-level KPIs tracking customer volume, total transactions, loan amounts, and overall account balances with dynamic filtering.
- **Customer Insights:** Deep dive into active vs. dormant accounts, account type distributions, and top customer transaction rankings.
- **Transactions:** Comprehensive analysis of transaction types (Payment, Transfer, Deposit, Withdrawal) and seasonal trends.
- **Loans & Details:** Portfolio breakdown by loan status, types, interest rates, and a dedicated drill-through details view for individual loans.
- **Support & Satisfaction:** Tracking customer support calls, resolution rates, and issue categories across regions.

## 🛠️ Tech Stack & Tools
- **UI/UX Design:** Figma (Dark mode theme, custom sidebar navigation, icons, and layout mockups)
- **Data Transformation & ETL:** Power Query
- **Data Modeling:** Star Schema architecture (Relational mapping between Customers, Loans, and Transactions)
- **Calculations:** Advanced DAX Measures
- **Visualization:** Power BI Desktop
